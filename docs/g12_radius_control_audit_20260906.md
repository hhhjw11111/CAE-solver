## 发现的问题

修复几何后的 0.13.1 G12 单次运行返回 PASS，但输出不满足基本算术自洽：

- R060 打印 H00 环带平均温升 `0.39960865517040373 K`；
- 同行组 H02 温升 `0.40986179770901437 K`；
- 打印对比量却为 `-4.8316705392860898%`。

这是一次真实的审计异常，不应根据输出正负来挑选结论。

源码中 `plain_values` 只有一列：在三个半径循环内先正确计算各自的 H00 虚拟环带和对比量，但在循环外打印时已被 R120 覆盖。因此 R060/R090 的 H00 参考值打印错误；对比量本身是在对应半径内计算的。无孔环带体积误差和分母有效性也只验收了最后一个半径，未完整落实冻结规范的“每个半径”要求。

## 最小修复

1. 使用 `plain_values(9,3)` 保存每个半径的无孔基准。
2. 使用 `plain_annulus_errors(3)` 保存每个虚拟环带的几何误差。
3. 在除法前逐一确认基准有限、严格为正，环带体积误差有限且在 `[0,2%)`。
4. 总体 H00 环带误差摘要改为三个半径的最大值，另输出每个半径的误差。
5. 每个半径输出其自身的 H00 值，再由其与 H02 值计算对比量。

不改变控制方程、材料、边界条件、Newton、网格或原有阈值。
