# G09 中心孔洞几何、边界与求解路径冻结规范 v1

## 1. 验证边界

G09 只回答：中心通孔网格进入已验证的七场求解器后，几何、边界标签、全局
Jacobian、Newton、continuation、守恒和确定性输出是否仍然正确。

G09 不回答孔洞是否导致某一物理量增大，也不把场峰值解释为网格无关的孔边
集中。孔径规律、局部加密和 C04 物理结论属于 G10 之后的工作。

## 2. 匹配算例

两组算例采用相同材料、外形、厚度、外边界离散和载荷：

- 外形：`600 nm x 600 nm x 20 nm`；
- 左端固定三个位移，左右端分别施加电势、电子/空穴对数浓度和温度 Dirichlet；
- 其余外表面为自然边界；孔壁不施加任何 Dirichlet 条件；
- 目标电压：`-5 V`；电压因子和焦耳因子均加载至 1；
- 材料：`TPS_G08_REFERENCE`。

无孔控制 `G09_H00_PLAIN_CONTROL` 使用 `4 x 4 x 1 = 16` 个 HEX20。有孔算例
`G09_H02_R090_COARSE` 使用中心半径 `90 nm` 的贯穿孔、16 个周向分区、2 个径向
分区和 1 个厚度分区，共 32 个曲边 HEX20。两组网格的每条外边均为 4 个二次面。

## 3. 预期拓扑

| 指标 | H00 无孔 | H02 有孔 |
|---|---:|---:|
| 节点数 | 155 | 304 |
| 单元数 | 16 | 32 |
| 左/右接触面数 | 4 / 4 | 4 / 4 |
| 左/右接触节点数 | 23 / 23 | 23 / 23 |
| 上/下表面数 | 16 / 16 | 32 / 32 |
| 孔壁面数 | 0 | 16 |
| 孔壁节点数 | 0 | 80 |
| 未分类边界面数 | 0 | 0 |

H02 的所有孔壁节点到板中心的半径必须在尺度相对容差内等于 `90 nm`，且不得
出现在任何 Dirichlet 节点集合中。所有边界面必须恰好出现一次，所有内部面必须
恰好出现两次，不允许非流形面。

## 4. 首次运行前冻结的通过条件

1. 两个网格所有积分点 Jacobian 行列式为正；
2. H00 体积相对解析长方体误差小于 `1E-12`；
3. H02 体积相对解析“正方体积减圆柱孔体积”误差小于 `1E-3`；
4. 第 3 节所有拓扑计数完全相等，孔壁无 Dirichlet 约束；
5. H02 最终收敛状态上的组合方向全局 Jacobian 中心差分最小相对误差小于
   `1E-6`，至少 3 个步长的误差小于 `1E-5`；
6. H00、H02 均完成 `(0,0)->(1,0)->(1,1)`，所有接受点残差和增量小于
   `1E-9`，四项守恒缺陷小于 `1E-8`，温度及两种载流子浓度有限且为正；
7. G09 重复运行逐字符一致，命令行与 Visual Studio 独立构建逐字符一致；
8. H00、H02 两个生产结果文件分别重复一致并与 Visual Studio 输出一致；
9. G00--G08 与 L01 不退化，旧 `Console3` 三个冻结哈希不改变。

首次失败后不得放宽几何、Jacobian、非线性或守恒阈值。若网格生成规则本身有
错误，必须保留失败记录并发布带原因的新版本规范。
