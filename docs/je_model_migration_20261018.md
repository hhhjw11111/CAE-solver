## 备份与模型身份

项目根目录 `solver_backups/HEAT_MIGRATION_20261018/` 分别保存原输入、源码/构建/协议、
原始结果、图件；10,005个归档成员已逐一SHA-256回读校验，另有项目元数据备份。
原文件全部留在原处；可再生PARDISO因子仅编目并原地保留。FAIL与superseded标签不改。

新研究明确设置 `heat_source_current_work=.true.`，采用
`Q = E·(Jn+Jp)`，保留局部符号，不截断负值，不加入SUPG补偿，不调整热源来凑平功率。
默认开关仍为false，历史输入仍执行原漂移电导热源。原生标识保留其诊断性质。
这个模型是R=0下的简化电流做功热模型，不是完整载流子/晶格热电能量闭合，也不是ZnO实验校准。
本轮不同时加入复合热、高场迁移率、Peltier/Thomson项或新的材料参数。

- NT：指数载流子，迁移率随温度变化，Einstein扩散系数随温度变化。
- N0：迁移率和扩散系数均冻结在参考温度。
- LQ：线性相对浓度，电流使用参考浓度；保留三阶段单向求解流程，不宣称七场完全回耦。
  LQ不启用当前不支持的SUPG/log-weighted离散。位移/应力可同时含电压一次项和二次项。
- 热通量保持 `q_heat=-k grad(T)`；热边界、其他方程和生产材料保持原定义。

更换热源会改变热反馈和所求方程的解，不等于解决高Pe空间离散问题。在标量Einstein关系下，
`Pe=mu*|E|*h/(2D)=q*|E|*h/(2*kB*T)`；相同E和h时降温反而会增大Pe。

## 第3步：独立验证与解析扩展

保留原A1、A2。原A1的电子/空穴电流分别为零，因此原解析场代入JE后仍然零热源。
需要新增非零电流的解析问题，不能把原A1温度场直接改名为含热验证。

1. A1JJE：复用真实本构、装配、Newton/延续、独立热流链路的均匀焦耳热闭式验证。
   原A1J默认入口和日志保持不变。
2. JEGRAD：恒定输运的线性载流子精确解。L=20um、W=20um、H=1um，
   n0=p0=1e21/m3，mu_n=.05、mu_p=.02 m2/(V s)，k=10 W/(m K)，T0=300K，V=.02V。
   `eta_n=eta_p=s*x/L`，`phi=-V*x/L`，s=-.05/0/+.05；
   `Q=q*N*((mu_n+mu_p)*E^2+(Dn-Dp)*E*s/L)`，
   `theta=Q*x*(L-x)/(2*k)`。真实求解nx=1/2/4及横向2×2×2网格。
   场/功率归一化误差门限1e-8，4/5阶积分差门限1e-10；温度用实际峰值归一化，不能以1K掩盖误差。
   另做非线性局部Boltzmann电流抵消、非零旧漂移热以及独立解析切线检查。
3. A2P：反平面压电闭式验证，u1=u2=0，u3=w，等温、均匀中性载流子。
   `F=x*(1+a^2/(x^2+y^2))`，孔壁法向导数为零。
   应力/电位移为 `sigma_3i=c44*w_,i+e15*phi_,i`、`D_i=e15*w_,i-eps*phi_,i`。
   电驱动仅给外边界phi=-E0F，w自然边界加单点锚：w=-(e15/c44)*phi+C；
   力驱动仅给外边界w=Gamma*F，phi自然边界加单点规范：phi=(e15/eps)*w+C。
   两个互补载荷与e15正/负/零控制，避免同时指定两场解析边界掩盖漏耦合。
   三层网格，场L2<1e-3，梯度<2%，孔壁归一化法向通量<1%，误差随细化下降。
   这是有反平面约束的合成基准，不是自由三维ZnO薄板；常数、层级和零场尺度在首算前单独冻结。
4. 运行G02JE/F1MJE/G04JE及相关SUPG切线，重新跑A1/A2，并做16项旧CLI逐字节回归。
   仅新增验证模块/可选验证参数，不改物理核心；新目录构建，不覆盖旧exe。

原独立通量审计的辅助diffusion_work在LQ下按实际浓度扣除漂移项，与LQ参考浓度电流不一致。
新验证独立计算正确分解，不用该辅助字段判断LQ扩散热；总JE、端口功率及热流不受此字段影响。
生产新后处理也不得沿用该错误辅助口径，或硬编码载流子扰动为零。
