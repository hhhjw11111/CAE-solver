# 原方程的对数加权弱式原型核验

本项属于原物理模型内的数值离散试验。R21 生产源码、已有可执行程序和正在运行的
A96 求解均未改变。原型位于 `tests/log_weighted_probe_m.f90`，链接冻结 R21 的
材料点、几何、原单元和验证对象文件。原型通过不意味着生产路径或三维网格通过。

## 动机与文献边界

现有程序虽然以 eta 为未知量，载流子方程仍采用原电流的普通弱式加 SUPG。
Pérez-Escudero 等的论文区分了直接代入对数变量与在建立弱式前对输运方程作
指数归一化；其 Remark 3 也讨论了非常温和变系数情形的常数归一化选择。
这仅提供候选离散方法，不证明它适合本项目的三维 HEX20 耦合问题。
来源：[Computational Mechanics, DOI 10.1007/s00466-024-02578-x](https://link.springer.com/article/10.1007/s00466-024-02578-x)。

## 本程序符号下的推导

保持 n=n0 exp(eta_n)、p=p0 exp(eta_p)，保持完整原物理电流、迁移率、扩散、
温度和漂移电导热源。对单个载流子选择试验函数 w_i=exp(-eta) N_i。
在本程序原残差的符号约定下，其积分为

`r_i = integral exp(-eta) [(grad N_i - N_i grad eta) dot J + s q N_i R] dV`，

其中电子 s=+1、空穴 s=-1，J 仍使用各自原物理电流。现有模型 R=0。
对正密度的连续解，这相当于将原输运 PDE 乘以正函数；零自然法向电流仍为零。
有限维测试空间改变，因此离散解可以不同，必须重新检查原物理通量和网格误差。

除材料点原有 dJ、dR 贡献外，一致切线必须包含试验函数的状态导数：

`delta[exp(-eta)(grad N_i-N_i grad eta)]`
`= exp(-eta)[-N_j(grad N_i-N_i grad eta)-N_i grad N_j] delta eta_j`。

反应项权重还产生 `-exp(-eta) N_j s q N_i R delta eta_j`。
原型显式实现这些项，没有用数值切线代替它们。力学、静电和热方程行逐系数
保留原单元结果；SUPG 与 LQ 组合在原型中拒绝，避免未经推导的叠加。

## 可复现入口与当前判据

原输入不启用新格式。显式选择新格式时，在 `solver_control` 使用：

```fortran
transport_supg=.false.,
transport_log_weighted=.true.,
log_weighted_quadrature_order=3,
```

只接受 NT/N0，禁止 SUPG/LQ 叠加；`run_hv_point.py --log-weighted` 生成对应输入，`--quadrature-order 5` 用于同一网格的积分敏感性对照。所有运行必须使用新的输出目录；种子场只作初值，必须重新解平衡。

验收分开记录：Newton 原双容差；独立电流/热流及对称切面门限；原 10 项全局/环域网格指标；相同可执行文件、相同网格 3/5 阶积分的 1% 对照；新增逐节点完整场的 2% 最大差异。载流子局部场误差用 `expm1(eta)` 的变化幅度归一化，不能用大参考浓度掩盖其变化误差。任何单项通过都不会自动产生 0–8 V 证书。
