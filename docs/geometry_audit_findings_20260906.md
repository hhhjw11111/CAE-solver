# 2026-09-06 HEX20 孔洞网格几何审计与修复

## 结论

原 G10/G12/G13 分级圆孔网格在体积分点上可以通过，但在孔壁等参边界迹上存在负 Jacobian。G11 也使用 G10-L2 网格，因而旧 G10–G13 孔洞结果不能继续作为最终物理证据。

根因是网格生成器对 HEX20 径向边中点再次施加了径向分级函数。本生成器的径向边为直边，修复时其中节点取两端角点的物理坐标中点，避免这一分级操作造成映射翻折。这不是“所有曲边中节点都必须取弦中点”的通用规则：孔壁周向曲边中节点仍按圆弧放置。

## 独立证据

独立脚本：

`scripts/audit_hex20_boundary_geometry.py`

原 R090-L2 网格的采样结果：

- 3×3×3 体积分点：PASS；
- 5×5×5 体积分点：PASS；
- 5×5 边界迹：FAIL，最小 `det J / ||J||_\infty^3 ≈ -8.23×10^{-3}`；
- 9×9×9 闭合采样：FAIL。

修复后 R090-L2：

- 3×3×3 体积分点：PASS；
- 5×5×5 体积分点：PASS；
- 5×5 边界迹：PASS，最小归一化 Jacobian约 `9.65×10^{-2}`；
- 9×9×9 闭合采样：PASS。

这类采样是强几何门禁，但不是对连续参数域全局正性的数学证明。
