# G06/V07 全局分块一致 Jacobian 审计冻结规范 v1

## 1. 审计目标

G06 检查生产模型 M2 的同一个全局映射

\[
\mathrm{assemble\_global\_system}(x)\longrightarrow\{R(x),J(x)\}
\]

是否满足

\[
J(x)v=\left.\frac{\mathrm dR(x+h v)}{\mathrm dh}\right|_{h=0}.
\]

G04 已检查一个混合方向；V07 必须把七个数值输入场分别隔离，防止不同 Jacobian 块的误差相互抵消。

## 2. 网格、状态和边界

- 网格：两个共享面的 HEX20 单元，尺寸为 \(2\,\mu\mathrm m\times1\,\mu\mathrm m\times1\,\mu\mathrm m\)。
- 未知量顺序：\([u_1,u_2,u_3,\phi,\eta_n,\eta_p,\theta]\)。
- 位移给出约 \(10^{-4}\) 的三维小应变；电场约 \(10^5\,\mathrm{V/m}\)。
- \(\eta_n\) 和 \(\eta_p\) 在单元尺度内分别变化约 \(0.05\)，温升在空间内变化数 K。
- 电压延续因子固定为 \(0.60\)，焦耳热因子固定为 \(0.77\)。
- 左端参考节点固定三个位移、电势、两种对数浓度和温升；右端参考节点规定电势。固定自由度的扰动严格为零。

## 3. 分块方式

残差行汇总为五组：

\[
[R_u,R_\phi,R_n,R_p,R_T].
\]

输入列分别扰动七个数值场：

\[
[u_1,u_2,u_3,\phi,\eta_n,\eta_p,\theta].
\]

因此首先产生 \(5\times7\) 数值误差表；随后把三个独立位移列取最大值，得到理论章节使用的 \(5\times5\) 物理块表。

冻结的结构零块为

\[
K_{u n},K_{u p},K_{n u},K_{n p},K_{p u},K_{p n},K_{T u}=0,
\]

其中 \(u\) 列包含三个独立位移分量。结构零块不仅检查解析 Jacobian 为零，也检查重新装配的有限差分泄漏。

## 4. 扰动、缩放和误差定义

七场特征尺度固定为

\[
S_x=[10^{-10},10^{-10},10^{-10},10^{-1},5\times10^{-2},
5\times10^{-2},5].
\]

每个场使用确定性的正弦—余弦方向，在该场的自由自由度上归一化后乘以对应特征尺度。

方程尺度由当前真实 Jacobian 冻结为

\[
(S_R)_i=\max_j |J_{ij}|(S_x)_j.
\]

使用中心差分和下列无量纲步长：

\[
h\in\{10^{-2},3\times10^{-3},10^{-3},3\times10^{-4},10^{-4},
3\times10^{-5},10^{-5},3\times10^{-6},10^{-6}\}.
\]

对残差组 \(a\) 和输入场 \(b\)，误差定义为

\[
e_{ab}(h)=
\frac{\|S_{R,a}^{-1}( [R_a(x+hv_b)-R_a(x-hv_b)]/(2h)-J_{ab}v_b )\|_2}
{\max\{1,\|S_{R,a}^{-1}J_{ab}v_b\|_2\}}.
\]

这一定义同时适用于强块和结构零块，不会用极小的零块范数放大舍入误差。

## 5. 首次运行前冻结的通过条件

- 所有 \(5\times7\) 块的最小误差均小于 \(10^{-6}\)。
- 每个非零块至少有三个步长满足 \(e_{ab}(h)<10^{-5}\)，以证明存在稳定误差区间，而不是单点偶然值。
- 所有结构零块的最大有限差分泄漏小于 \(10^{-12}\)。
- 固定自由度方向严格为零；所有试探状态保持正温度和有限浓度。
- 两次命令行运行逐字符一致；Visual Studio 清洁构建为零错误、零警告，并与命令行输出逐字符一致。

阈值、状态、步长和结构零表在首次运行前冻结。失败时只能修复推导、装配、边界或缩放，不得通过删除失败块或放宽阈值获得通过。
