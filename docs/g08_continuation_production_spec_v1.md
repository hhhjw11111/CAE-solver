# G08 电压—焦耳热 continuation、重启与生产执行冻结规范 v1

## 1. 验证目标

G08 在 G07 已验证的单载荷点 Newton 外层实现确定性 continuation：

1. 在 `joule_factor=0` 时将 `voltage_factor` 从 0 推进至 1；
2. 固定 `voltage_factor=1`，再将 `joule_factor` 从 0 推进至 1；
3. 每个候选载荷点只调用 G07 的 `solve_single_load_newton`；
4. 失败候选不得覆盖最后一个已接受状态，步长按冻结规则回退后重试；
5. 接受点必须记录载荷、Newton 指标、温度/浓度范围和四项离散守恒缺陷。

G08 同时开放版本化 M2 `run` 入口，但仍不运行孔洞 C04。

## 2. 冻结 continuation 算法

载荷路径记为

\[
(\lambda_V,\lambda_J):
(0,0)\rightarrow(1,0)\rightarrow(1,1).
\]

冻结参数：

- 初始步长：1；
- 最小步长：\(1/16\)；
- 最大步长：1；
- 失败回退因子：0.5；
- 快速收敛增长因子：2；
- 单候选点 Newton 上限：8；
- 总尝试上限：64；
- Newton 迭代不超过 3 次时，下一步增长；达到 7 次时，下一步减半。

每个候选点从最后一个已接受状态的独立副本开始。Newton 失败时，必须满足

\[
\|x_{\mathrm{checkpoint}}^{\mathrm{after}}-
x_{\mathrm{checkpoint}}^{\mathrm{before}}\|_\infty=0.
\]

达到最小步长仍失败、超过尝试上限或路径顺序非法时必须显式失败。

## 3. 核心验证算例

- 沿用 G07 的两个共享面 HEX20 微米棒、双载流子平衡参考材料和边界条件；
- 目标电压为 \(-10\,\mathrm V\)，目标电压和焦耳因子均为 1；
- 初始状态全部为零，在起点投影边界并用 Newton 证明起点平衡；
- 完整路径结束后，从 \((1,0)\) 的已保存检查点单独重启焦耳热阶段；
- 重启不得复用完整路径的最终解。

## 4. 生产输入与可信输出

生产命令冻结为

```text
TPSolverV2.exe run <case.nml> <result.dat>
```

`case.nml` 使用 schema version 2，并为 M2 增加 `problem_control` 与
`solver_control` 组。G08 只放行显式命名的 `REFERENCE_BAR` 问题和
`TPS_G08_REFERENCE` 材料配置；未知配置必须失败，不能静默使用默认材料。

结果文件必须包含：

- 求解器、理论和架构版本；
- case id、网格规模、最终载荷；
- 每个接受点的阶段、载荷、Newton 指标和四项守恒缺陷；
- 每个节点的坐标、七个未知量以及由 \(\eta_n,\eta_p\) 恢复的正浓度；
- 不包含当前时间、随机数或绝对路径。

命令行重复运行和 Visual Studio 独立构建必须生成逐字符相同的标准输出与结果文件。

## 5. 首次运行前冻结的通过条件

- 完整路径达到 \((1,1)\)，所有接受点 Newton 收敛；
- 至少发生一次拒绝和步长回退，以实际覆盖检查点恢复分支；
- 拒绝候选对检查点的最大改变量严格为 0；
- 所有接受点的残差和增量满足 G07 的 \(10^{-9}\) 容差；
- 所有接受点的四项守恒缺陷均小于 \(10^{-8}\)；
- 所有接受点温度、电子浓度、空穴浓度均为有限正数；
- 从 \((1,0)\) 重启所得最终解与完整路径最终解的七场缩放 RMS 差小于
  \(10^{-12}\)；
- 生产 `run` 成功，结果文件结构完整，节点浓度有限正；
- G00--G07 与 L01 全部不退化；两次命令行、两次生产输出以及 Visual Studio
  交叉构建逐字符一致，构建为 0 错误、0 警告。

状态、路径、材料、步长规则、输入和阈值在首次运行前冻结。失败时只能修复
continuation、Newton 调用、检查点、输入、输出或守恒实现，不得删除失败分支或放宽阈值。
