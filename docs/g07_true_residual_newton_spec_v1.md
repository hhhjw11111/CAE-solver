# G07 真实残差阻尼 Newton 与守恒验证冻结规范 v1

## 1. 验证目标

G07 验证生产模型 M2 的单载荷点非线性求解链：

\[
J(x_k)\,\Delta x_k=-R(x_k),\qquad
x_{k+1}=x_k+\lambda_k\Delta x_k.
\]

Newton、线搜索和最终审计必须调用同一个
`assemble_global_system`。线搜索不得复用旧矩阵估计残差，必须在每个试探状态
重新装配真实残差。

G07 不加入电压或焦耳热 continuation，也不运行 C04。

## 2. Newton 与 Armijo 契约

- 七场变量尺度固定为

\[
S_x=[10^{-10},10^{-10},10^{-10},10,10^{-1},10^{-1},10].
\]

- 每次 Newton 迭代根据当前 Jacobian 形成行尺度

\[
(S_R)_i=\max_j |J_{ij}|(S_x)_j.
\]

- PARDISO 求解无量纲增量方程

\[
(S_R^{-1}JS_x)\,\Delta\hat x=-S_R^{-1}R,
\qquad \Delta x=S_x\Delta\hat x.
\]

- Dirichlet 自由度的增量严格为零；每个试探状态再次投影边界值。
- 冻结当前迭代的 \(S_R\)，定义真实残差功函数

\[
\Psi(x)=\frac{1}{2N_f}\|S_R^{-1}R(x)\|_2^2.
\]

- 从 \(\lambda=1\) 开始，以 0.5 回退。对精确 Newton 方向，重新装配的试探残差满足

\[
\Psi(x_k+\lambda\Delta x_k)
\le (1-2c_1\lambda)\Psi(x_k),\qquad c_1=10^{-4}
\]

才接受；最小步长为 \(10^{-8}\)。无合法步长时必须显式失败。
- 最大 Newton 次数 25；残差 RMS 和已接受增量 RMS 均须小于 \(10^{-9}\)。

## 3. 冻结物理算例

- 网格：两个共享面的 HEX20 单元，尺寸
  \(2\,\mu\mathrm m\times1\,\mu\mathrm m\times1\,\mu\mathrm m\)。
- 材料：G02 已验证的各向异性双载流子材料；电子和空穴参考浓度取热平衡值。
- 单载荷点：`voltage_factor=1`，`joule_factor=1`。
- 左端电势 0，右端电势 \(-10\,\mathrm V\)。
- 左、右端均固定 \(\eta_n=\eta_p=0\)，表示平衡欧姆接触。
- 左、右端温升均为 0，表示等温热沉。
- 左端面三个机械位移均为 0；其余表面采用当前弱形式的自然边界。

同一载荷点使用两个确定性初值：

1. 物理型初值：线性电势、零位移、零浓度增量和零温升；
2. 冷启动初值：除投影的边界值外全部为零。

两次计算不得互相传递解。

## 4. 守恒与可接受性

最终解重新进行有约束和无约束装配。对每个守恒场，将无约束残差分成自由行与
Dirichlet 反力行。自由行总和相对于该场无约束残差绝对和的比值为全局平衡缺陷。

必须报告：

- 电势方程的电荷—电通量平衡；
- 电子和空穴电流的接触通量平衡；
- 热源与热沉反力的热平衡；
- Dirichlet 边界最大误差；
- 积分点最小/最大温度、电子浓度和空穴浓度。

## 5. 首次运行前冻结的通过条件

- 两个初值均在 25 次以内收敛；
- 最终残差 RMS 和增量 RMS 均小于 \(10^{-9}\)；
- 每个已接受步均满足真实残差 Armijo 条件；
- 两个最终解的七场缩放 RMS 差小于 \(10^{-7}\)；
- 所有四个全局平衡缺陷均小于 \(10^{-8}\)；
- Dirichlet 最大误差小于 \(10^{-14}\)；
- 积分点绝对温度、电子浓度和空穴浓度均为有限正数；
- G00--G06 与 L01 不退化；两次命令行输出逐字符一致；Visual Studio 清洁构建
  为 0 错误、0 警告，并与命令行输出逐字符一致。

状态、初值、尺度、步长规则和阈值在首次 G07 运行前冻结。若失败，只能修复算法、
方程、装配、缩放或边界实现；不得删除失败初值或放宽阈值。

## 6. 首次冻结运行记录与算法修复

首次运行中，物理型初值在 5 次 Newton 内收敛；冷启动在第 25 次仍未收敛。
失败态的温度、电子浓度和电势已经接近物理型解，但空穴浓度范围被过大的
\(\eta_p\) 更新推至约 \(10^{-33}\) 到 \(10^3\,\mathrm{m^{-3}}\)，而收敛解为空穴浓度
约 \(10^{11}\,\mathrm{m^{-3}}\)。PARDISO 无扰动主元，全部接受步满足原 Armijo 条件，
因此失败归因于指数变量的 Newton 步缺少全局化保护，而不是 Jacobian 或线性求解错误。

修复后，每个试探步除原 Armijo 条件外，还必须满足

\[
\max_a\{|\lambda\Delta\eta_{n,a}|,|\lambda\Delta\eta_{p,a}|\}\le1.
\]

不满足时仍按冻结的 0.5 因子回退。该保护使单步浓度变化倍数限制在
\([e^{-1},e]\)，只约束到达同一非线性根的路径，不修改控制方程、最终解或任何通过阈值。

上述全局步长保护的第二次运行仍在 25 次上限失败：它阻止了空穴浓度塌陷，但一个
极端空穴节点迫使七个场累计回退 160 次，残差仅从 0.254 降至 0.128。由此将保护
修正为分量信赖域：只把每个 \(\Delta\eta_n\)、\(\Delta\eta_p\) 分量截断至
\([-1,1]\)，不缩小位移、电势和温度方向。对于该受限方向 \(d\)，Armijo 条件使用
实际方向导数

\[
\Psi(x_k+\lambda d)\le
\Psi(x_k)+c_1\lambda\,\frac{(S_R^{-1}R)^T
(S_R^{-1}JS_x)(S_x^{-1}d)}{N_f}.
\]

当未触发信赖域时，\(d=\Delta x\)，该式严格退化为第 2 节的原 Newton Armijo 条件。
若受限方向不是下降方向则显式失败。两个初值、25 次上限和全部通过阈值保持不变。
