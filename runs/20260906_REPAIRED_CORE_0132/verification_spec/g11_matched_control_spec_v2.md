# G11 收敛网格 H00/H02 匹配对照规范（修正版 v2）

状态：在首次采用切割单元细分的 G11-v2 物理指标产生前冻结。

## 修正原因

G11-v1 的求解、拓扑、守恒和跨构建复现全部通过，但新增的后验诊断显示：固定 `5 x 5 x 3` Gauss 点直接用几何指示函数截取虚拟环带时，H00 环带体积误差为 `7.89%`，H02 为 `0.84%`。H00 的环带内外圆弧都切过有限元，固定点选择不足以支撑精确局部比较。

v1 证据目录保持不变；v2 不修改控制方程、网格、材料、边界、Newton、continuation 或 G10 判据，只提高 G11 公共环带的独立后处理精度。

## 冻结修正

G11-v2 沿用 `g11_matched_control_spec_v1.md` 的全部设置与物理观测量，但对每个 HEX20 单元的 `(r,s)` 自然坐标面执行 `8 x 8` 均匀子单元划分，每个子单元继续使用 `5 x 5` Gauss 点，厚度方向使用 3 点 Gauss。

因此局部指标的有效面内积分规则为 40×40 点，但按有限元自然坐标的子区间分别映射，专门降低圆环指示函数切割单元造成的积分误差。

## 新增的预冻结门禁

公共环带解析体积为

```text
V_annulus = pi * ((120 nm)^2 - (90 nm)^2) * 20 nm
```

除 v1 全部通过条件外，v2 还要求：

- H00 数值环带体积相对解析误差 `< 2%`；
- H02 数值环带体积相对解析误差 `< 2%`。

若任一失败，不得放宽阈值；应增加子单元数并建立新版本规范。

## 结果使用规则

只有通过 v2 新门禁、双次命令行精确重复和 Visual Studio 交叉构建后，G11 的局部 H00/H02 百分比才可作为后续孔径矩阵的基准。v1 局部百分比保留为诊断历史，不作为最终定量结果。
