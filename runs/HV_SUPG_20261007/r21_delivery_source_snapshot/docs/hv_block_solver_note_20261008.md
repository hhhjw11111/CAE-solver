# R18：完整矩阵检查保护的空穴分块求解

R19 补充：可选分块候选的两个 CSR 图仅省去精确为零的非对角项，保留全部
非零系数及每个对角位置。没有按大小丢弃系数，完整矩阵逐行检查及失败回退仍在。
BLK 制造矩阵包含显式零项，并检查实际压缩；普通/Debug BLK、G07、TCTRL 通过。
R19 默认 16 项旧 CLI 仍逐字节一致。该存储变化不保证在每种矩阵上都更快；
运行时间比较必须使用相同初猜及可比机器负载，不把并行运行的耗时当作加速比。

用户继续要求完成 0–8 V 验收。40,192 节点的原全矩阵磁盘分解耗时较长，
因此增加默认关闭的线性求解选项，控制方程、离散残差、Jacobian 和非线性门限不变。

按空穴自由度划分已经尺度化的 Newton 系统：

```text
[ A  B ] [dx_primary] = [b_primary]
[ C  D ] [dx_hole   ]   [b_hole   ]
```

先尝试解 A，再解 D，并保留 C 的全部作用。B 的逐行相对量超过 `1e-10` 时，
直接使用原完整矩阵。否则形成候选解，再用**完整的 A/B/C/D 和原右端**逐行检查
`abs(A_full*x-b) / (abs(A_full)*abs(x)+abs(b))`，最大值必须不超过 `1e-11`。
零右端的单对角约束先精确恢复。非有限量、块求解失败或后向误差超限均回退原求解器。
没有把 B 从原模型、残差或最终检查中删除；允许的线性误差小于原 Newton `1e-9` 门限。
该后向误差不是对病态系统前向误差的证明，因此仍保留真实场和非线性/流量验证。

当前 ZnO 候选的极小空穴参考浓度和 R=0 使其适合尝试这种分块；不假设所有材料
都有弱空穴反馈，也不自动将它用于旧输入。`TPS_PARDISO_SPLIT_HOLES=1` 才启用，
Python 单点和温度续接入口对应显式 `--split-holes`。默认路径的 16 项旧 CLI
仍逐字节一致，见 `runs/HV_SUPG_20261007/regression_r18/report.json`。

`verify BLK` 检查三个制造系统：无反向耦合时接受；较强反向耦合时回退；
反向耦合系数虽小但空穴增量很大时，由完整矩阵检查发现错误并回退。
三个系统的解误差不超过 `2.23e-16`；后两种回退与原完整求解完全相同。
G07/TCTRL 在选项启用时通过，包含实际接受与回退路径；高 Pe SUPG 解析验证通过。
Debug BLK/G07/TCTRL 同样通过。

3 V NT 生产检查对空穴 log 初猜施加最大约 0.00955 的扰动，未改其它六字段。
4 次分块候选的完整矩阵后向误差最大 `6.03e-16`，最终满足原双容差和独立流量。
与之前完整 3 V 状态相比，最大按冻结输入尺度归一的节点差为 `3.25e-11`，
温升极值相同，电流相对差 `3.05e-13`。这不是对所有材料或网格的无条件性能保证。

## OOC 运行隔离

`--storage OOC --ooc-core-mb 12000` 使用既有 PARDISO 磁盘模式，独立目录为
该新输出目录下的 `pardiso_ooc/`。记录配置和环境，不继承其它运行的文件前缀；
MAX_SWAP_SIZE 保持 0。该预算只针对 PARDISO，不包含装配数组和系统/其它应用。
方法和环境变量定义见 [Intel oneMKL 文档](https://www.intel.com/content/www/us/en/docs/onemkl/developer-reference-c/2026-0/onemkl-pardiso-parallel-direct-sparse-solver-iface.html)。

R17 的 IC/OOC G07 预检查均通过，温度极值相同，浓度极值最大相对差 `4.93e-14`；
严格 stdout 字节对照为 FAIL，保留判定，不宣称存储模式逐字节可复现。
存储或分块检查通过均不授予任何高压点网格、稳定化或物理模型适用性通过。
