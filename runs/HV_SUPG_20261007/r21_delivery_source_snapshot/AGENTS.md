# TPSolverV2 长期开发规则

## 项目定位

本目录是当前有效的 TPSolverV2 多物理场 CAE/FEM 求解器基准，实际实现包括三维 HEX20 有限元、力学、压电、热传导、双载流子漂移—扩散、漂移电导型 Joule 热、多物理场耦合、Newton 非线性求解和稀疏直接线性求解。

## 事实来源

事实优先级固定为：

1. `src/` 当前源码；
2. `cases/`、`runs/` 和验证入口产生的实际证据；
3. `README.md` 与 `docs/` 当前文档；
4. 历史聊天记录。

聊天记录不得覆盖已被源码或验证推翻的结论。旧目录、旧可执行文件和 superseded 结果只能用于明确的历史追溯。

## 核心代码修改

修改前必须确认涉及的物理或数值模块、控制方程、残差、Jacobian，以及受影响的 V/G/A 验证。修改后至少编译、运行受影响验证、检查残差与守恒，并报告结果变化。程序收敛不等于物理结果正确。

## 数值规则

- Newton 收敛与空间离散正确性必须分开判断。
- 高 Péclet 漂移—扩散问题不能只靠 Newton 或线搜索参数解决。
- 修改输运稳定化时必须同时检查 residual、Jacobian 和低 Pe 回归。
- 不得无说明放宽收敛阈值或验收阈值来制造 PASS。
- 失败的历史结果不能作为当前证据。

## 当前模型边界

- 每节点字段顺序固定为 `u1,u2,u3,phi,eta_n,eta_p,theta`，共 7 个自由度。
- 当前代码使用 SI 单位和 HEX20 单元。
- 非线性载流子浓度为 `n=n0*exp(eta_n)`、`p=p0*exp(eta_p)`；LQ 是明确的一阶线性相对浓度模型，N0/NT 按源码定义区分输运冻结与温度相关输运。
- 当前 Joule 热是漂移电导项，不应表述为完整漂移—扩散能量热源。
- 当前复合实现为 `R=0`。
- 产生—复合、陷阱、施主不完全电离、高场迁移率、时间积分和其他未实现物理不得在结果解释中假装已包含。

## 验证与结果保护

核心修改应优先重新运行解析验证，再运行受影响的单元、全局、Newton、延续和生产验证。任何 FAIL 都不能被图件或论文结论绕过。不得擅自删除或覆盖 `runs/` 中的历史证据、冻结输入或 provenance；不得使用已 superseded 的旧孔洞结果；生成结果、构建产物和源码必须保持可区分。
