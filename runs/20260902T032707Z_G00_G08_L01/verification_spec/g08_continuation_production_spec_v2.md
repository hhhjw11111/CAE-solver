# G08 continuation 验证规范 v2：首次运行后的预注册修订

## 修订原因

v1 在 2026-09-02 的第一次冻结运行中得到完整收敛解，但未触发预期的失败回退：

- 电压一步加载恰好在第 8 次 Newton 迭代收敛；
- v1 的单候选点 Newton 上限也恰好为 8；
- 焦耳热一步加载在 6 次迭代内收敛；
- 因而完整路径的拒绝次数为 0，v1 仅因“至少一次拒绝”条件失败；
- 该次运行的最大守恒缺陷为 `1.1285162448915259E-016`，重启解差为 0。

拒绝一个已经满足残差和增量容差的第 8 次迭代结果会改变 Newton 收敛语义，
因此不采用该做法。v2 保留 v1 的物理路径、材料、目标、电压、容差、步长和
8 次主路径上限；只把失败回退的分支覆盖拆分为一个额外的严格算法压力子检验。

## v2 验证矩阵

1. **主路径**：完全沿用 v1，单候选点上限为 8，验证物理解、守恒和检查点；
2. **回退压力路径**：使用相同初态、网格、物理目标、步长和容差，仅把单候选点
   Newton 上限严格收紧为 7，使已观测的首次整步电压尝试失败；
3. **重启路径**：从主路径保存的 `(1,0)` 检查点开始，沿用 v1 的 8 次上限；
4. 三条路径均必须达到各自目标；压力路径必须实际发生至少一次拒绝，且拒绝时
   已接受检查点的最大变化严格为 0；
5. 主路径、压力路径和重启路径的最终解两两缩放 RMS 差均小于 `1E-12`；
6. v1 的其他通过条件不变，不放宽任何物理、残差、增量、守恒或重启阈值。

这项修订只增强算法分支覆盖，不改变生产求解器的默认参数，也不把验证专用限制
带入正式 `run` 路径。
