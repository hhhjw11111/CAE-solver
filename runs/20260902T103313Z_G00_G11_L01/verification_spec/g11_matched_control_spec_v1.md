# G11 收敛网格 H00/H02 匹配对照规范（冻结版 v1）

状态：在首次 G11 数值结果产生前冻结。

## 1. 目的

G10 已证明 `r=90 nm, -5 V` 的 H02 孔洞解在选定积分型指标上网格稳定。G11 的目的，是在同一外边界离散下建立无孔 H00 对照，从而把“几何缺陷效应”与“外边界网格差异”分开。

G11 是受控数值比较，不是实验验证，也不预设孔洞一定使某个指标增大。

## 2. 两个冻结算例

共同设置：

- 外形 `600 nm x 600 nm x 20 nm`；
- `M2_THERMO_TWO_CARRIER`；
- `TPS_G08_REFERENCE` 材料；
- 右端相对左端 `-5 V`；
- 相同 Newton、线搜索、缩放与 continuation 参数；
- 左右电学/热学接触和左端机械约束相同。

差异仅为：

- H00-L2：无孔，`8 x 8 x 1` 个 HEX20 单元，531 节点、64 单元；
- H02-L2：中心通孔 `r=90 nm`，复用 G10-L2，1056 节点、128 单元。

H00 的每条外边具有 8 个二次单元。非均匀边界节点按

```text
x(q) = L/2 + (L/2) tan(pi q / 4),  q in [-1,1]
```

生成，使四条外边的 HEX20 边界节点与 G10-L2 的圆孔到方边射线映射逐点一致。

## 3. 可比区域与观测量

除全域量外，在两个几何中都评价同一个物理区域：

```text
90 nm <= distance_to_center <= 120 nm
```

H00 中它是“虚拟孔边环带”，H02 中它是实际孔边外侧 30 nm 环带。两者均由独立 `5 x 5 x 3` Gauss 后处理评价。

冻结比较量：

1. 总焦耳功率；
2. 全域平均焦耳热；
3. 环带焦耳热加权均值与加权 95% 分位数；
4. 环带电场模量加权均值；
5. 环带 `|n/n0-1|` 与 `|p/p0-1|` 加权均值；
6. 环带 `|T-T0|` 加权均值；
7. 环带位移模量加权均值。

相对几何效应统一定义为

```text
C = (H02 - H00) / H00
```

正值表示孔洞算例的该指标较大，负值表示较小。

## 4. 预先冻结的数值通过条件

- H00/H02 四条外边的边界节点集合最大双向最近距离 `< 1e-18 m`；
- 两者材料、模型、目标电压和 continuation 终点一致；
- H00：531 节点、64 单元、无孔壁面、每条侧边 8 个面、左右各 43 个接触节点；
- H02：1056 节点、128 单元、32 个孔壁面、160 个孔壁节点、每条侧边 8 个面、左右各 43 个接触节点；
- 未分类外表面数为 0，孔壁与 Dirichlet 节点无重叠；
- 所有积分点 Jacobian 行列式为正；体积相对解析值误差 `< 1e-3`；
- 两个非线性解都到达 `voltage_factor=1`、`joule_factor=1`；
- 每个接受点的缩放残差和缩放更新 `< 1e-9`；
- 最大守恒缺陷 `< 1e-8`，边界误差 `< 1e-14`；
- 所有冻结观测量有限且非负，形成相对差值所需的 H00 分母为正。

任何物理差值的符号或大小都不是 PASS 条件。若结果与假设不符，应检查机理而不是改判据。

## 5. 解释边界

G11 通过后，可以把 H00/H02 的差值称为“当前冻结模型在该工况下的孔洞几何效应”。仍不能称为真实材料缺陷效应；后者需要材料校准、文献/实验对比，以及半径和电压参数研究。
