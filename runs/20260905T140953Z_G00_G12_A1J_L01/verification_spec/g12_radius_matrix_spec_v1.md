# G12 中心孔半径矩阵规范（冻结版 v1）

状态：在首次 G12 数值结果产生前冻结。

## 1. 目的

G12 在已经通过 G10 的局部网格收敛和 G11-v2 的匹配 H00/H02 对照基础上，固定电压 `-5 V`，扫描中心孔半径 `60/90/120 nm`。目的不是证明单调规律，而是确认当前冻结程序可以对半径变化进行可复现、可比较的计算。

## 2. 算例矩阵

共同条件：`600 nm x 600 nm x 20 nm`，`M2_THERMO_TWO_CARRIER`，`TPS_G08_REFERENCE`，右端相对左端 `-5 V`，相同 Newton、线搜索、缩放和 continuation 参数。

| 标签 | 几何 | 网格 | 节点/单元 |
|---|---|---|---:|
| H00 | 无孔控制板 | 匹配外边界 L2 | 531 / 64 |
| R060 | 中心孔 `r=60 nm` | 周向 32、径向 4、二次径向分级 | 1056 / 128 |
| R090 | 中心孔 `r=90 nm` | 同上 | 1056 / 128 |
| R120 | 中心孔 `r=120 nm` | 同上 | 1056 / 128 |

三种有孔网格的外边界节点必须与 H00-L2 逐点匹配；改变半径只改变孔边到外边界的内部映射。厚度方向均为 1 个 HEX20 单元。

## 3. 可比区域和观测量

对每个半径 `r_h`，在 H00 中使用虚拟环带 `r_h <= r <= r_h+30 nm`，在对应有孔算例中使用实际孔边外侧同一环带。采用 G11-v2 的 `8 x 8` 面内切割单元细分、每个子单元 `5 x 5 x 3` Gauss 后处理。

冻结观测量：总焦耳功率、全域平均焦耳热、环带焦耳热均值和 p95、环带电场均值、电子相对浓度偏移、空穴相对浓度偏移、温升均值、位移模量均值。几何效应定义为

```text
C(r_h) = [H02(r_h) - H00(virtual r_h)] / H00(virtual r_h)
```

## 4. 数值通过条件

- H00 和三个有孔算例均到达完整电压/Joule 载荷；
- 每个接受点缩放残差和缩放更新 `<1e-9`；最大守恒缺陷 `<1e-8`，边界误差 `<1e-14`；
- 所有积分点 Jacobian 行列式为正，未分类外边界为 0，孔壁 Dirichlet 重叠为 0；
- H00 节点/单元数为 `531/64`，每个有孔算例为 `1056/128`；
- 所有有孔算例孔壁面/孔壁节点为 `32/160`，左右接触节点均为 `43`；
- 每个几何的总体积相对解析值误差 `<1e-3`；
- 每个 H00 虚拟环带和有孔实际环带的独立积分体积误差 `<2%`；
- 所有观测量有限，H00 分母严格为正。

任何 `C(60)`, `C(90)`, `C(120)` 的符号或单调性都不是 PASS 条件。若半径曲线不单调，应报告该事实并检查机理，不能修改判据。

## 5. 解释边界

G12 通过后，只能说明当前冻结模型在一个固定电压下能够稳定地产生半径参数矩阵及其 H00 对照差值。由于 G10 的严格三层网格收敛是在 `r=90 nm` 完成的，`r=60/120 nm` 的出版级定量使用前仍应增加端点网格敏感性检查；G12 不替代该检查，也不替代实验或文献验证。
