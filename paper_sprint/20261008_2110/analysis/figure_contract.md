# 3 V 后处理图件契约

本轮只重构已存 HEX20 场，不启动三维求解；F1 六例用于粗网格模型对照，R23/R25 单独作为既有 NT 数值路线证据。所有图直接标注 L0 探索或 mesh pending；既有 3.01% 局部载流子 FAIL 保持不变。

核心图件论点：电场、温度和载流子响应可以从真实原始场重现，但空间准确性与漂移热源解释仍受明确限制。图件采用 quantitative grid，Python/matplotlib，白底、可编辑 SVG 与 PDF、PNG 检查图、CSV 图源；不加统计误差条，不将离散敏感性作为概率区间。

冻结的后处理选择：五阶张量 Gauss 积分；节点电势范围 Pe（不称内部极值）；N0/LQ 用 T0 的 D/μ，NT 用单元节点平均温度；区域按单元几何中心依序分为触及 x=±10 μm 端面的第一层单元为接触区、上下表层 |z|≥0.45 μm、孔周 r≤3.5 μm、体内其余区。H0 的孔周位置仅为相同空间区域，不用于环带增强比。计数比例与 detJ 体积加权比例分列。厚度线冻结为 (x,y)=(0,3.25 μm)，d=0.25 μm，全部处于孔外材料。应力采用半径3.25 μm中面、单元内侧迹，不做节点平滑；位移仅减去该厚度线中面平移，厚度变化保留原始上下表面差，不去除真实均匀应变。

颜色不得制造差异；H0/H1 温度和电场同指标共同色标。导出标签用英文避免中文字体依赖，中文图注写入报告。图件不宣称材料实验标定或真实器件热力学闭合。

修订记录：初始接触区中心|x|≥9μm在部分网格为空；在解读分区前改为触及x=±10μm端面的第一层单元，并在region_definition_correction.json保存原因。其余分区顺序不变，物理与全域指标不变。
